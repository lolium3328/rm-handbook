## 2. 每章的统一骨架

每个二级小节按固定四段写，缺一段就算没写完：

1. **该写什么** —— 这一节要交付的知识点，条目化，不写导语。
2. **案例 / 证据** —— 挂一个真实场景（导航撞墙、识别抖动、频率不够、实车翻车），先给现象与数据，再给分析。
3. **读者自检** —— 3 个左右的问题，答不上来说明没读进去。
4. **待补** —— 需要一手资料、实验数据或代码链接才能写的部分。

## 3. 写作约定

- **案例先行**：先出现象和数据，再出现名词和定义。禁止「本节介绍……」式开场。
- **不劝学**：不写「记住这条」「多练就好」「不要害怕」。直接给机制、给命令、给参数。
- **可执行**：涉及工具和代码的地方给可直接复制的命令、最小可跑例、预期输出。
- **写清判据**：凡是「应该」「一般」「通常」，替换成阈值、频率、毫秒数、误差量级或明确的取舍条件。
- **术语中英并列**，首次出现给英文，因为新人查资料用的是英文。
