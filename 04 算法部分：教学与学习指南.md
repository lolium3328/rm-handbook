# 04 算法部分：教学与学习指南

它不是算法教科书，而是一份「地图」：说明算法组的工作分成哪些部分、每部分要学什么，以及资料和开源工程该去哪里找、怎么找。

## 04-00 总览与学习方法

### 1 每个方向都分「算法」和「实现」两层

| 层次 | 学什么                                                      | 典型资料                                       |
| ---- | ----------------------------------------------------------- | ---------------------------------------------- |
| 算法 | 原理、数学推导、假设与适用条件；与具体框架无关              | 教材、论文、算法合集                           |
| 实现 | 在 ROS 2 等框架中落地：节点、话题、参数、launch、调试与部署 | 官方文档、其他学校整理的教程、高校战队开源工程 |

推荐的学习方式是「先跑通，再补原理，最后改模块」：

1. 先在仿真或录好的数据上跑通一个开源工程，建立对整条链路的印象；
2. 再回到算法层，逐个模块补齐原理；
3. 最后在实现层调参、替换或改进模块，并按 01 章的方法验证效果。

### 2 方向总览

| 方向     | 对象                                         | 主要模块                             |
| -------- | -------------------------------------------- | ------------------------------------ |
| 视觉算法 | 步兵、英雄、哨兵、无人机的自瞄；飞镖         | 标定、检测、位姿解算、跟踪预测、弹道 |
| 导航算法 | 哨兵                                         | 定位建图、地形分析、规划、决策       |
| 强化学习 | 平衡步兵、足式等机构的运动控制；部分决策问题 | 建模、仿真、训练、Sim-to-Real、部署  |

#### 4.1 算法合集与教材

这一类资料的共同点是原理与可运行代码放在一起：读完一段推导，就能运行、修改对应的代码并观察结果。建议每个方向先选一到两份作为入门主线，其余作为查阅用的参考书。表中「层次」一列说明它主要服务于算法层还是实现层。

| 名称                                                                                                                 | 方向                       | 层次        | 说明                                                                                                                                        |
| -------------------------------------------------------------------------------------------------------------------- | -------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| [PythonRobotics](https://atsushisakai.github.io/PythonRobotics/)                                                      | 导航                       | 算法        | 机器人算法的 Python 合集适合先建立「有哪些模块」的整体印象                                                                                  |
| [Kalman and Bayesian Filters in Python](https://github.com/rlabbe/Kalman-and-Bayesian-Filters-in-Python)              | 状态估计（视觉、导航通用） | 算法        | 覆盖卡尔曼滤波、EKF、UKF、粒子滤波，侧重直觉而非形式化证明；自瞄的 EKF 跟踪和导航的状态估计都可以从这里入门                                 |
| [Modern Robotics](https://github.com/NxRLab/ModernRobotics)（Lynch、Park）                                            | 机器人通用                 | 算法 + 实现 | 运动学、动力学、规划与控制教材，配套 Python / MATLAB / Mathematica 代码库，函数按书中章节组织；代码以易读为目标，不追求效率                 |
| [视觉SLAM十四讲（第二版）+ slambook2](https://github.com/gaoxiang12/slambook2)（高翔等）                              | 视觉、导航                 | 算法 + 实现 | C++ 代码按章节组织，建议本地编译运行后再修改；相机模型、李群李代数、非线性优化、PnP、回环检测同时是自瞄与导航定位的基础                     |
| [OpenCV Tutorials](https://docs.opencv.org)                                                                           | 视觉                       | 实现        | 图像处理、相机标定、solvePnP 等都有官方示例，可与传统装甲板识别代码对照阅读                                                                 |
| [动手学深度学习（d2l）](https://zh.d2l.ai)                                                                            | 深度学习                   | 算法 + 实现 | 免费在线的中文教材，数学公式直接对应可运行代码；含卷积网络与计算机视觉章节，是深度学习装甲板识别的前置                                      |
| [蘑菇书 EasyRL（Datawhale）](https://datawhalechina.github.io/easy-rl/)                                               | 强化学习                   | 算法        | 中文强化学习教程，整理自李宏毅《深度强化学习》、周博磊《强化学习纲要》等课程，可在线阅读；适合作为中文入门主线                              |
| [Reinforcement Learning: An Introduction（第二版，Sutton、Barto）](http://incompleteideas.net/book/the-book-2nd.html) | 强化学习                   | 算法        | 强化学习标准教材，作者主页提供免费 PDF、代码与勘误；系统讲 MDP、时序差分、函数逼近、策略梯度，理论上遇到问题时以它为准                      |
| [OpenAI Spinning Up](https://spinningup.openai.com)                                                                   | 强化学习                   | 算法 + 实现 | 深度强化学习入门资料：术语与理论介绍、关键论文清单、核心算法的短小独立实现和练习。目前处于维护模式，以参考阅读为主                          |
| [CleanRL](https://github.com/vwxyzjn/cleanrl)                                                                         | 强化学习                   | 实现        | 每个算法变体一个独立文件（如 ppo.py、dqn.py），全部实现细节集中在一处，并做过基准测试；适合读懂 PPO 的工程细节后再去看 Isaac Lab 等训练框架 |
